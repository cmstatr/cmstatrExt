# p-Value for one-sample equivalency

**\[deprecated\]**

Use
[`p_equiv_one_sample()`](https://cmstatrExt.cmstatr.net/reference/p_equiv_one_sample.md)
instead of `p_equiv()`.

## Usage

``` r
p_equiv(m, t1, t2)
```

## Arguments

- m:

  the size of the acceptance sample

- t1:

  the test statistic described above. May be a vector.

- t2:

  the test statistic described above. May be a vector.
